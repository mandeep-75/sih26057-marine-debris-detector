WINDOWS SETUP & RUN — Marine Debris Detection (SIH26057 · MoES/NIOT)
====================================================================

Project layout
--------------
  frontend\            React + Vite web application
    public\models\     ONNX model files used for in-browser inference
    src\               detection, review, insights, and reporting UI
  dev.cmd              one-command frontend launcher
  dev.sh               macOS/Linux frontend launcher

Prereqs
-------
  Node.js 20 LTS or newer, including npm

Setup
-----

  1. Open Command Prompt.
  2. Navigate to the project directory.
  3. Install frontend dependencies:

       cd frontend
       npm install

Run
---

  cd C:\path\to\hack\frontend
  npm run dev

  Open http://localhost:5173

One-command launcher
--------------------

  cd C:\path\to\hack
  dev.cmd

Production build
----------------

  cd C:\path\to\hack\frontend
  npm run build
